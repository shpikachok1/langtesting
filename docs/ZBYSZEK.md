# Живой Збышек: голос, анимация, исправление ошибок

## Как это будет выглядеть

Экран как видеозвонок: в центре нарисованный Збышек в своём такси. Ты зажимаешь кнопку
микрофона и говоришь. Он хмурится, слушая, потом отвечает голосом, губы двигаются в такт словам,
лицо меняется: ржёт, закатывает глаза, злится. Под ним появляются субтитры с переводом
и карточка «✏️ ошибки»: что ты сказал не так и какие звуки произнёс плохо.

## Как это устроено

```
🎙️ твой голос
   │
   ▼
1. Распознавание речи + оценка произношения (Azure Speech, pl-PL)
   → текст того, что ты сказал, и оценка каждого слова и звука
   │
   ▼
2. Мозг Збышека (Gemini, через нашу серверную функцию)
   получает: твою фразу, оценки произношения, твой уровень, выученные слова
   отвечает JSON-ом: { реплика, эмоция, перевод, ошибки[] }
   │
   ▼
3. Голос (Azure TTS, польский мужской голос)
   → аудио + «виземы»: какая форма рта в какую миллисекунду
   │
   ▼
4. Анимация (Rive): виземы двигают рот, эмоция переключает выражение лица
```

Почему так:
- **Azure Speech** закрывает сразу три вещи: распознаёт польский, оценивает произношение
  по звукам (Pronunciation Assessment) и озвучивает с виземами для движения губ.
- **Rive** даёт векторную анимацию персонажа с «машиной состояний»: рот, моргание, эмоции
  переключаются из кода. Работает в React Native, весит мало.
- **Русская речь Збышека** в начале курса озвучивается русским голосом, польская — польским.
  Реплика делится на куски по языку.

## Сколько это стоит

Мозг Збышека работает на Gemini API, ключ берётся в aistudio.google.com.
Подписка claude.ai на приложение никак не влияет.

### Мозг (Gemini), одна реплика Збышека

Примерно 2 000 токенов на входе (характер, история диалога, твой уровень) и около 200 на выходе.

| Модель | Цена за 1M токенов (вход / выход) | Одна реплика | Месяц по 30 мин в день (~60 реплик) |
|---|---|---|---|
| gemini-3.8-flash, бесплатный тариф | $0 | $0 | $0, пока влезаешь в лимиты |
| gemini-3.8-flash, платно до 31.12.2026 | $0.75 / $3.75 | ~$0.002 | ~$4 |
| gemini-3.8-flash, платно с 2027 | $1.50 / $7.50 | ~$0.0045 | ~$8 |
| gemini-3.5-flash-lite, платно | $0.30 / $2.50 | ~$0.001 | ~$2 |

Цены с ai.google.dev/gemini-api/docs/pricing на 02.10.2026. Учти: на бесплатном тарифе
Google может использовать переписку для улучшения своих моделей.

### Голос

У Azure Speech есть бесплатный тариф: несколько часов распознавания и сотни тысяч символов
озвучки в месяц. Для одного человека по 15 минут в день этого, скорее всего, хватит.
Точные лимиты проверю, когда будем подключать.

### Смена модели

Характер лежит в `supabase/functions/chat/prompt.ts`, вызов модели — в `index.ts`.
Модель меняется секретом `GEMINI_MODEL`, другой провайдер — заменой одного `index.ts`.

## Этапы

1. Подключить Supabase и ключ Gemini, чтобы Збышек ответил текстом.
2. Голос: микрофон → Azure → текст и оценка произношения; ответ озвучивается.
3. Анимация: персонаж в Rive, движение губ по виземам, эмоции.
4. Карточка ошибок после каждой реплики и сводка после разговора («сегодня ты 5 раз сказал „sz“ как „ш“»).
