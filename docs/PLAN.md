# Polski z kopem — план

Личное приложение для изучения польского (потом английский, казахский) в стиле Duolingo
плюс режим живого разговора с персонажем.

**Цель:** пройти собеседование на Карту поляка, потом жить в Польше. Занятия 20–30 минут в день.

## Стек

| Что | Чем | Почему |
|---|---|---|
| Приложение iOS + Android | React Native + Expo, TypeScript | Один код на обе платформы, тестить можно сразу на телефоне через Expo Go |
| Аккаунт и синхронизация | Supabase (Postgres + Auth) | Бесплатный тариф, прогресс одинаковый на всех устройствах |
| Собеседник | Gemini API (gemini-3.8-flash) через Supabase Edge Function | Есть бесплатный тариф; ключ лежит на сервере, а не в приложении |
| Озвучка польского | expo-speech (голос телефона) | Бесплатно и офлайн; позже можно заменить на более живой TTS |
| Проверка произношения | Azure Speech, Pronunciation Assessment (pl-PL) | Даёт оценку по каждому слову и звуку, а не просто «распознал/не распознал» |

## Как устроено

```
App.tsx                      переключение экранов
content/pl/course.json       весь курс польского: юниты → уроки → слова + упражнения
src/types.ts                 формат курса
src/content.ts               загрузка курса по коду языка
src/progress.ts              XP, серия дней, пройденные уроки; доля польского у собеседника
src/screens/HomeScreen.tsx   дорожка уроков как в Duolingo
src/screens/LessonScreen.tsx новые слова → упражнения, 3 сердечки, ошибки возвращаются в конец
src/screens/ChatScreen.tsx   чат со Збышеком: перевод по тапу, карточки ошибок, лицо по эмоции
src/screens/ReviewScreen.tsx повторение слов карточками
src/review.ts                интервальное повторение (коробки Лейтнера)
supabase/functions/chat      сервер Збышека: index.ts — вызов Gemini, prompt.ts — характер
```

**Курс — это данные.** Новый урок = новый объект в `course.json`. Новый язык = папка
`content/en/course.json` и одна строка в `src/content.ts`. Код трогать не нужно.

Типы уроков: слова (`vocab`), грамматика (`grammar`, теория с таблицами и примерами),
чтение (`reading`, текст с переводом по тапу и вопросами на понимание).
Типы упражнений: выбор варианта, сборка перевода из слов, аудирование.

Слова пройденных уроков попадают в повторение и возвращаются через 1, 3, 7, 14, 30… дней.

## Режим разговора

Персонаж — Збышек, краковский таксист. Грубость на максимум: матерится, жёстко стебёт за ошибки,
но не трогает национальность, внешность и семью. Разговор свободный, иногда сам сворачивает
на темы собеседования на Карту поляка. Отвечает JSON-ом: реплика, перевод, эмоция, список ошибок.
Доля польского в его речи считается из прогресса: 10% на старте, +3% за каждый пройденный урок,
до 95%. Он знает, какие слова ты уже прошёл, и опирается на них. Ошибки в польском поправляет
в конце реплики. Долгое нажатие на его сообщение — озвучка.

## Этапы

1. ✅ Каркас: дорожка уроков, упражнения, XP и серия, экран чата.
2. ✅ Повторение слов, уроки грамматики и чтения, первый юнит «Карта поляка», Збышек на Gemini.
3. Подключить Supabase: вход, синхронизация прогресса, деплой функции `chat` с ключом Gemini.
4. Голос Збышека: микрофон → распознавание (Azure) → ответ голосом. Отдельный режим
   «тренировка произношения»: Збышек даёт фразу, ты повторяешь, он оценивает каждый звук.
5. Анимация Збышека в Rive: губы по виземам, эмоции.
6. Контент A1–A2 под Карту поляка: числа, семья, город, еда, время; история Польши,
   праздники (Wigilia, Wielkanoc, 11 listopada), символы, известные поляки; тренировочное
   собеседование с консулом.
7. Фан: анимации и звуки, ачивки, цель на день.
8. Английский и казахский курсы.

## Что нужно от тебя

- Ключ Gemini API (aistudio.google.com) и проект Supabase, когда дойдём до этапа 3.
- Ключ Azure Speech на этапе 4. Ключи никогда не коммитим, они идут в секреты Supabase.
