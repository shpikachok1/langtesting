# Polski z kopem — план

Личное приложение для изучения польского (потом английский, казахский) в стиле Duolingo
плюс режим живого разговора с персонажем.

## Стек

| Что | Чем | Почему |
|---|---|---|
| Приложение iOS + Android | React Native + Expo, TypeScript | Один код на обе платформы, тестить можно сразу на телефоне через Expo Go |
| Аккаунт и синхронизация | Supabase (Postgres + Auth) | Бесплатный тариф, прогресс одинаковый на всех устройствах |
| Собеседник | Claude API через Supabase Edge Function | Ключ лежит на сервере, а не в приложении |
| Озвучка польского | expo-speech (голос телефона) | Бесплатно и офлайн; позже можно заменить на более живой TTS |
| Проверка произношения | Azure Speech, Pronunciation Assessment (pl-PL) | Даёт оценку по каждому слову и звуку, а не просто «распознал/не распознал» |

## Как устроено

```
App.tsx                      переключение экранов
content/pl/course.json       весь курс польского: юниты → уроки → слова + упражнения
src/types.ts                 формат курса
src/content.ts               загрузка курса по коду языка
src/progress.ts              XP, серия дней, пройденные уроки; доля польского у собеседника
src/screens/HomeScreen.tsx   дорожка уроков как в Duolingo
src/screens/LessonScreen.tsx новые слова → упражнения, 3 сердечки, ошибки возвращаются в конец
src/screens/ChatScreen.tsx   чат со Збышеком
supabase/functions/chat      серверная часть собеседника (промпт персонажа)
```

**Курс — это данные.** Новый урок = новый объект в `course.json`. Новый язык = папка
`content/en/course.json` и одна строка в `src/content.ts`. Код трогать не нужно.

Типы упражнений сейчас: выбор варианта, сборка перевода из слов, аудирование.

## Режим разговора

Персонаж — Збышек, ворчливый краковский таксист. Грубоват, подкалывает, но без оскорблений.
Доля польского в его речи считается из прогресса: 10% на старте, +3% за каждый пройденный урок,
до 95%. Он знает, какие слова ты уже прошёл, и опирается на них. Ошибки в польском поправляет
в конце реплики. Долгое нажатие на его сообщение — озвучка.

## Этапы

1. ✅ Каркас: дорожка уроков, 5 уроков польского, упражнения, XP и серия, экран чата.
2. Подключить Supabase: вход, таблица прогресса, синхронизация между устройствами.
3. Запустить собеседника: задеплоить функцию `chat`, вписать адрес в `.env`.
4. Голос: кнопка микрофона в чате и упражнение «произнеси», оценка произношения через Azure.
5. Больше контента: юниты A1 (числа, семья, еда, город, время), повторение слов по интервалам.
6. Фан: анимации и звуки, ачивки, лиги/цели на день, напоминания.
7. Английский и казахский курсы.
