# Как открыть приложение на телефоне через Expo Go

## 1. Один раз: подготовить компьютер

1. Установи **Node.js** версии LTS: https://nodejs.org (кнопка «LTS», дальше «Далее, Далее, Готово»).
2. Установи **Git**: https://git-scm.com/downloads.
3. Проверь в терминале (Windows: PowerShell, Mac: Terminal):
   ```bash
   node -v   # должно показать v20 или выше
   git --version
   ```

## 2. Один раз: подготовить телефон

Поставь приложение **Expo Go**:
- iPhone: App Store → «Expo Go»
- Android: Google Play → «Expo Go»

Если Expo Go уже стоял, обнови его до последней версии.

## 3. Скачать проект

```bash
git clone https://github.com/shpikachok1/langtesting.git
cd langtesting
npm install
```

`npm install` скачивает зависимости, это займёт пару минут. Повторять его нужно только после того, как в проект добавятся новые библиотеки.

## 4. Запустить

```bash
npx expo start
```

В терминале появится QR-код.

- **iPhone:** открой обычную **Камеру**, наведи на QR-код и нажми на всплывшую ссылку «Открыть в Expo Go».
- **Android:** открой **Expo Go** → «Scan QR code» и наведи на код.

Первая загрузка идёт 20–60 секунд, потом откроется дорожка уроков.

Пока сервер запущен, любое изменение кода сразу появляется на телефоне. Остановить сервер: `Ctrl + C`.

## 5. Обновить до новой версии

```bash
git pull
npm install
npx expo start
```

## Если что-то не так

| Проблема | Что делать |
|---|---|
| Телефон крутит загрузку и падает с ошибкой сети | Телефон и компьютер должны быть в одной Wi-Fi сети. Если не помогает (университетский Wi-Fi, VPN), запусти `npx expo start --tunnel` |
| «Project is incompatible with this version of Expo Go» | Обнови Expo Go в магазине приложений. Проект на Expo SDK 57 |
| `npx: command not found` / `node не является командой` | Node.js не установился или терминал открыт до установки. Перезапусти терминал |
| QR-код не видно или он «поехал» | В терминале нажми `s` или открой ссылку `exp://…` из терминала вручную в Expo Go |
| Нет звука в упражнениях | Выключи беззвучный режим на iPhone (переключатель сбоку) и проверь громкость |
| Красный экран с ошибкой | Сделай скрин и пришли мне |

Чат со Збышеком пока отвечает заглушкой: серверная часть ещё не подключена.
